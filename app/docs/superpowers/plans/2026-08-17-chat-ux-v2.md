# Chat UX v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the owner-approved batch of chat-panel + agent improvements (thinking stream, history, confirm polish, batch approval, attach-as-context, investment tools + page awareness, dock/resize, web access) on `claude/financial-advisor-agent-44b9f5`.

**Architecture:** The agent panel is a client React tree (`AgentWidget` owns `useAgentChat`; `ChatPanel` is presentational) talking to an SSE route (`/api/agent/chat`) that pumps a provider-agnostic agent loop (`runAgent`) over gated tools. Most changes are additive: new pure helpers + unit tests, new `gate:'none'` read tools, a new gated `import_statement` tool, one new affordance kind (`confirm_batch`), a server-backed history endpoint, and a client layout/resize layer. The two SSE-protocol touch points (`thinking` frames already on the wire; a new `viewContext`/`attachment`/`action.scope` in the POST body) are backward-compatible.

**Tech Stack:** Next.js 15 (App Router), React 19, TypeScript, Tailwind 4, `better-sqlite3` + Drizzle, vitest, `@anthropic-ai/sdk`, `react-markdown`.

**Spec:** `app/docs/superpowers/specs/2026-08-17-chat-ux-v2.md` (read it — this plan argues from it; both travel together).
