# Speculative products — options and similar

Some instruments can produce very high returns but carry very high risk. Treat
them as speculation, not core investing.

- **Options: stay away unless you are an expert.** Options can pay off big but
  can also go to zero fast. Options trading is close to a zero-sum game — for
  every winner there's a loser, minus fees — so it is not a reliable way to build
  long-term wealth. Only engage if you genuinely have the expertise, and only
  with money you can afford to lose.
- **Keep speculation out of the core portfolio.** The long-term portfolio should
  be broad, low-cost index funds (see `portfolio-allocation`). Any speculative
  position is separate and small, never a substitute for the core.
- **Beware "high return" pitches** that don't discuss the matching downside risk.

General education, not personalized advice.
