# Financial priorities — the order to put dollars to work

A rough priority order for where each additional dollar should go. Earlier
steps generally come before later ones, but they overlap (e.g. keep investing
in a 401(k) match even while paying down debt).

1. **Pay off high-interest debt first.** Credit-card balances, personal loans,
   and anything roughly 10%+ (often 20%+) APR. Paying these off is a guaranteed
   return equal to the interest rate. See `high-interest-debt`.
2. **Build an emergency fund.** ~6 months of expenses in a high-yield / money
   market account, adjusted up or down for job security and risk tolerance.
   See `emergency-fund`.
3. **Invest early and consistently.** Start as soon as the above are underway to
   let compounding work. Build a low-cost stock/bond portfolio. See
   `portfolio-allocation`.
4. **Maximize tax-advantaged accounts.** 401(k) (at least the match, ideally the
   max), Roth IRA, HSA; then after-tax / backdoor and mega-backdoor Roth. See
   `tax-advantaged-accounts`.
5. **Fund education goals (if any).** For kids heading to college, a separate
   529 plan, contributing early. See `education-529`.
6. **Park money for large near-term purchases conservatively.** For a house down
   payment or similar, money market funds or CDs — safe but still earning. See
   `large-purchase-savings`.

This is a general framework, not personalized advice. Read the specific topic
docs for detail, and use the user's actual accounts, balances, and spending
(available via tools) to ground any concrete suggestion.
